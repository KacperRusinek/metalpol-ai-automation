# metalpol-ai-automation
# Metalpol AI Automation  Projekt przedstawia propozycję automatyzacji procesu reklamacji dla firmy Metalpol Sp. z o.o.  Celem rozwiązania jest: - skrócenie czasu obsługi reklamacji, - automatyczna klasyfikacja zgłoszeń, - integracja SAP + JIRA, - poprawa jakości danych, - wdrożenie AI-assisted complaint processing.
